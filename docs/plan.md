# Perlead plan (v0.1 summary)

Approved 2026-11-22. This is the short public version of the plan.

## Positioning

A digital B2B product for tech companies and any business that wants to improve its B2B sales: a follow-up system that installs into the company's AI agent. Not a course.

Promise: every lead gets its own memory, every follow-up is written from that lead's history, and a human sends.

## Why it can win

Free agent templates already draft follow-ups, and paid AI SDRs sell volume. The gap Perlead fills:

- a dossier per lead where every fact has a source,
- a judge that stops drafts without evidence,
- learning from the owner's edits,
- honest measurement that can be published,
- a done-for-you setup for teams that will not configure it themselves.

## Validation (14 days, targets are hypotheses)

- 50 Starter installs, 10 paid packs, 2 setups sold, 2 of 3 pilots finishing with complete data.
- Continue if 3 of 4 targets are met. Iterate if many installs and few purchases. Stop if under 15 installs and 0 setups.

## Phases

1. Skills v0.1 (this repo).
2. Clean install test on a fresh agent.
3. Case 0 written up (done in `case-study/`).
4. Landing and checkout (landing in `web/`, checkout TODO).
5. Pilots found through the AIBD Scout playbook (`docs/outreach-playbook.md`).
6. Launch.
7. Decision; if it continues, a server with license keys for updates and aggregated benchmarks.

## Risks

- Free templates covering part of this: compete on proof, depth and setup.
- Agent memory reliability: dossiers live in a sheet or CRM.
- Deliverability: low volume, from the owner's own inbox.
- Platform rules on LinkedIn and X: drafts only, a human sends.
- Copying: assumed; value is in setup, updates and proof.
